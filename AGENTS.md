# Agent Instructions

Before working on this repository, read and follow:

- [Caveman communication rules](.github/instructions/caveman.instructions.md)
- [Ponytail engineering rules](.github/instructions/ponytail.instructions.md)

## Project Conventions

- Use Python 3.12+ syntax and manage dependencies with `uv`.
- Write code, variables, and filenames in English. Write learning docstrings and comments in German.
- Follow Ruff defaults and keep lines around 100 characters.
- Keep lessons small, runnable on their own, and clear in their output.
- Explain concepts from scratch before comparing them with external libraries.
- Prefer educational clarity over production-style abstraction.
- Add or update tests when behavior changes.

## Documentation

- Keep each topic's README accurate when its examples or explanations change.
- Update the top-level README when module status, roadmap, setup, or usage changes.
- Use the top-level README for the project overview, learning roadmap, and commands; do not duplicate them here.
